Assignment

Assignment can be thought of as storing information in an object of a chosen name. Can simply use <- or = to assign. An object name can be as simple as one letter or one number:

x <- 5
y = "five"
x
y
## [1] 5
## [1] "five"

<- is preferable to = because it shows the directionality of the assignment. Also, = could be confused with == (we’ll get to that).

To show assignment, we will use the built-in constant LETTERS but store it under a smaller object name.
